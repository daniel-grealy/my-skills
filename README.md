# my-skills

Custom Claude skills.

| Skill | Use |
|---|---|
| spec-not-procedure | Briefing an agent on an open problem without a gameable metric |
| phone-web-app | Building a small phone-app-like PWA on Cloudflare Pages + D1 |
| mummify | Making thesis-grade text followable by a lay reader |
| focused | Short answers in simplified technical English |
| brainstorm | Thinking something through with Claude |
| writing-assistant | Coaching you to write, without writing for you |

## Install

**Claude Code**
```
/plugin marketplace add daniel-grealy/my-skills
/plugin install my-skills@my-skills
```

**Claude.ai**: download a zip from Releases, then Settings > Skills > Upload skill.
